# N빵 정산기 (차수별 · 술/음료 분리)

회식·모임에서 1차·2차·3차 차수별로 **음식(전체)**, **술(음주자)**, **음료(비음주자)**를 자동 분리 계산하는 모바일 친화적 N빵 정산 웹앱입니다.

- **바로 사용하기:** https://gktkdrbs2218-dev.github.io/nbbang-calc/

## 주요 기능
- **무제한 차수/장소 추가:** 장소명 수정, 차수별 일괄 참석 지정(`전원 술` / `전원 술X` / `전원 불참`)
- **술/음료 자동 분리:** 음식은 전체 참석자, 술은 `술` 참석자, 음료는 `술X` 참석자끼리 자동 분배
- **절사/반올림 선택:** `100원 미만 버림`(기본), `100원 단위 반올림`, `1원 단위`
- **결과 링크 공유 (`#s=...`):** 별도 서버 없이 URL 해시만으로 정산 결과를 모바일에서 바로 공유
- **카카오톡 공유용 텍스트 복사:** 인앱 브라우저에서도 복사할 수 있는 텍스트 박스 폴백 지원
- **입금 계좌 자동 저장:** 브라우저 `localStorage`에만 로컬 저장
